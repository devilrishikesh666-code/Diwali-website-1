# Happy Diwali Website

A single-page, responsive Diwali celebration website built with plain HTML, CSS and JavaScript.

## Features
- Animated hero with floating diyas and sparkles
- Interactive diya lighting with a celebration when all are lit
- Festival story, rangoli gallery, and the Five Days of Diwali
- Wishes board saved in the browser (localStorage)
- Click-to-launch fireworks
- Mobile menu and reduced-motion support

## Run locally
Open `index.html` in any browser.

## Deploy with GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
